# P14 overlay UI — trang tóm tắt

`index.html` ở đây là bản tóm tắt (một màn gameplay có HUD, nhãn khách, toast, panel Kho; và một Daily Report có lãi) để hệ thống tự chụp ở 390/768/1440 px.

Tài liệu giải thích đầy đủ (mục tiêu, người dùng, luồng, quyết định, component, tự soát, nguồn) nằm ở [`../NOTES.md`](../NOTES.md). Mọi màn và trạng thái chi tiết nằm ở `../main-menu.html`, `../hud.html`, `../prep.html`, `../report.html`; token ở `../tokens.json`.
